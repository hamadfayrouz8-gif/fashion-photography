# Fashion Photography Website

A responsive fashion photography website recreated using HTML and CSS as a web development practice project.

## 🌐 Live Demo

[View Live Website](https://hamadfayrouz8-gif.github.io/fashion-photography/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## ✨ Features

- Responsive design
- Fashion photography portfolio layout
- Responsive navigation bar
- Portfolio gallery
- Services section
- Contact and social media sections
- Fixed Buy Now and Customize buttons
